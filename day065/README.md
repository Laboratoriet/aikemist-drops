# Day 065: Placeholder Image Generator

**URL:** https://day065.aikemist.com

Generate custom placeholder images for mockups and prototypes.

## Features

- **Custom Dimensions** — Any size up to 4000×4000
- **Size Presets** — 1920×1080, 1280×720, 800×600, OG Image, Instagram, etc.
- **Custom Colors** — Background and text color pickers
- **Color Presets** — Gray, Blue, Green, Red, Purple, Dark
- **Custom Text** — Override dimension text with your own
- **Format Options** — PNG, JPEG, WebP
- **Data URL** — Copy the image as a data URI
- **Download** — Save to disk
- **Randomize** — Generate random combinations
- **Light/Dark Theme**

## Use Cases

- Mockups and wireframes
- Development placeholders
- Quick thumbnails
- Testing layouts

## Tech

- Pure HTML/CSS/JS with Canvas API
- ~8KB total

## Monetization Potential

- **Current:** Portfolio only
- **Upgrade path:** API for programmatic generation, bulk generation, custom patterns/gradients
- **Estimated effort:** Low
