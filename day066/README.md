# Day 066: Emoji Picker

**URL:** https://day066.aikemist.com

Search and copy emojis instantly.

## Features

- **1000+ Emojis** — Smileys, Gestures, People, Animals, Food, Nature, Objects, Symbols, Flags
- **Category Tabs** — Browse by category
- **Search** — Find emojis by typing
- **Click to Copy** — One-click copy to clipboard
- **Recently Used** — Tracks your last 20 emojis
- **Light/Dark Theme**

## Tech

- Pure HTML/CSS/JS
- ~15KB total
- LocalStorage for recent emojis
