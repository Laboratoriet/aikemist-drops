# Day 063: Markdown Table Generator

**URL:** https://day063.aikemist.com

Create markdown tables visually. No more counting pipes and dashes.

## Features

- **Visual Editor** — Click and type, like a spreadsheet
- **Add/Remove** — Columns and rows with one click
- **Column Alignment** — Left, center, right per column
- **Import CSV/TSV** — Paste from Excel, Sheets, or CSV files
- **Compact Mode** — Toggle between pretty and minimal output
- **Live Preview** — See how your table will render
- **Copy Markdown** — One-click copy
- **Tab Navigation** — Tab through cells like a spreadsheet
- **Pipe Escaping** — Automatically escapes | in content
- **Light/Dark Theme**

## Keyboard Shortcuts

- `Tab` / `Shift+Tab` — Navigate cells
- `C` — Copy markdown
- `T` — Toggle theme
- `Esc` — Close import modal

## Tech

- Pure HTML/CSS/JS
- ~12KB total
- No dependencies

- **Current:** Portfolio only
