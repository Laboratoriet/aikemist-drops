# Day 064: Noise Texture Generator

**URL:** https://day064.aikemist.com

Generate procedural noise patterns for backgrounds and textures.

## Features

- **6 Noise Types** — Perlin, Simplex, Worley, FBM, Turbulence, Ridged
- **9 Presets** — Clouds, Marble, Wood, Static, Fabric, Paper, Smoke, Terrain, Cells
- **Full Control** — Scale, Octaves, Persistence, Contrast
- **Custom Colors** — Two-color gradient with swap button
- **Export Sizes** — 256, 512, 1024, 2048 pixels
- **Seamless Mode** — Generate tileable textures
- **Invert Toggle** — Flip colors
- **Randomize** — Generate random configurations
- **Download PNG** — Export high-quality images
- **Light/Dark Theme**

## Use Cases

- Website backgrounds
- Game textures
- Design assets
- Overlay effects
- Print materials

## Tech

- Pure HTML/CSS/JS with Canvas API
- Custom Simplex noise implementation
- ~15KB total

## Monetization Potential

- **Current:** Portfolio only
- **Upgrade path:** 4K export, animated GIFs, custom color gradients, Figma plugin
- **Estimated effort:** Medium
