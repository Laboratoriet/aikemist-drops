# Day 062: JWT Decoder

**URL:** https://day062.aikemist.com

Decode and inspect JSON Web Tokens instantly. See header, payload, and signature with syntax highlighting. 100% client-side — tokens never leave your browser.

## Features

- **Instant Decoding** — Auto-decodes as you type/paste
- **Color-coded Structure** — Header (red), Payload (purple), Signature (cyan)
- **Syntax Highlighting** — JSON with key/value color coding
- **Standard Claims** — Parsed display of iss, sub, aud, iat, exp, nbf, jti
- **Expiry Status** — Shows valid/expired with relative time
- **Algorithm Info** — Descriptions for HS256, RS256, ES256, etc.
- **Sample Tokens** — 4 examples: Basic, Expired, Admin, OAuth
- **Shareable URLs** — Link with token encoded for sharing
- **Character Count** — Track token length
- **Copy Sections** — One-click copy for header, payload, signature
- **Light/Dark Theme** — System-aware with manual toggle
- **Keyboard Shortcuts** — Ctrl+Enter, V, X, T

## Security

- 100% client-side processing
- No data sent to any server
- Tokens stay in your browser

## Tech

- Pure HTML/CSS/JS
- JetBrains Mono for code
- Jost for UI
- ~15KB total

## Monetization Potential

- **Current:** Portfolio only
- **Upgrade path:** API for programmatic decoding, batch processing, signature verification with secret/key
- **Estimated effort:** Medium
